# ClaudeSkillsHub
One stop shop for all my claude skills

## Skills

- `cover-letter-writer` — Writes a voice-matched cover letter from a job description and the candidate's resume.
- `daily-job-search` — Finds software, ML, AI, and infrastructure roles posted in the last 72 hours and emails a tabulated shortlist.
- `full-job-automation` — Runs the whole job hunt: searches for new roles posted in the last 72 hours, writes tailored cover letters via cover-letter-writer, applies on company career sites, tracks every application, and prepares recruiter cold-email drafts.
- `recruiter-email-finder` — Finds a recruiter or hiring manager, guesses their work email from public patterns, and scores how confident that guess is.
